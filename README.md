# TATA Online Retail Project

## Data Analysis & Business Intelligence Dashboard

This project focuses on analyzing **online retail sales data** to identify important business trends, revenue-driving factors, customer behavior, and high-performing products and countries.

The project combines **Python for data analysis** and **Microsoft Power BI for interactive data visualization**, turning raw retail data into meaningful business insights that can support data-driven decision-making.

---

## Project Overview

The objective of this project is to analyze the performance of an online retail business and answer important business questions from both **operational and marketing perspectives**.

The analysis focuses on:

* Understanding overall sales performance
* Identifying major revenue-generating factors
* Finding top-performing products
* Analyzing sales across countries
* Understanding customer purchasing behavior
* Identifying high-value customers
* Discovering sales trends and patterns
* Creating meaningful KPIs and interactive dashboards
* Providing actionable insights for business growth

This project is inspired by the **TATA Data Visualisation: Empowering Business with Effective Insights** virtual experience case study, where an online retail business requires data-driven insights for strategic planning.

---

## Business Problem

An online retail company wants to understand **what factors are contributing most to its revenue** and how its performance can be improved in the future.

Management is particularly interested in:

* Revenue and sales performance
* Product demand
* Customer purchasing patterns
* Geographic performance
* Business growth opportunities
* Marketing-related insights

The goal is to transform raw transactional data into **clear and actionable business insights**.

---

## Dataset

The project uses an **Online Retail transactional dataset** containing information about customer purchases.

### Important Columns

| Column        | Description                       |
| ------------- | --------------------------------- |
| `InvoiceNo`   | Unique transaction/invoice number |
| `StockCode`   | Unique product code               |
| `Description` | Product description               |
| `Quantity`    | Number of units purchased         |
| `InvoiceDate` | Date and time of transaction      |
| `UnitPrice`   | Price per unit                    |
| `CustomerID`  | Unique customer identifier        |
| `Country`     | Customer's country                |

The repository contains the dataset as `Online Retail.xlsx`.
